# Project history

## Aether: the pre-existing project

Aether is the long-running research and engineering workspace. Its record includes runtime design, verifier lifecycle, custom and benchmark-derived evaluation work, VM qualification, model/provider diagnostics, and a deep-synthesis program. The ledger is the historical authority. Where a lane is incomplete or a result is non-promotable, the history keeps that qualification.

## Build Week: the meaningful extension

During the Build Week evidence window, the work concentrated on authoritative-source reconstruction, execution/evidence boundaries, Architect/Solver/Verifier qualification, deterministic certification, provider-contract repairs, and preparing a public-facing product surface. The package in this repository is the concrete public extension: it makes the core role separation installable and judge-runnable without private infrastructure.

## Proteus: the submission

Proteus is not a retroactive rename of six months of work. It is the packaged product derived from Aether and the Build Week changes. Its public claim is narrow and testable: task truth can be compiled into a bounded workbench; a Solver can execute real actions; the runtime records evidence; and an independent Verifier can accept or reject the resulting state.

## Built with Codex

Codex/GPT-5.6-assisted work was used during Build Week for repository archaeology, source/evidence reconciliation, implementation, eval design, adversarial review, and packaging. This statement is intentionally paired with the ledger and commit references in [build-week.md](build-week.md); it is not a claim that every historical Aether change was produced during Build Week or by one model.
